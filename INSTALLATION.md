# Installation

1. Ouvre le dépôt `Leo0957/Leo0957` sur GitHub.
2. Supprime l'ancien fichier `profile-dashboard.svg` ou l'ancienne bannière si tu ne l'utilises plus.
3. Envoie les deux fichiers `README.md` et `banner.png` à la racine du dépôt.
4. Remplace l'ancien `README.md` si GitHub le demande.
5. Valide avec **Commit changes**.

Le fichier `banner.png` est exactement l'image demandée, sans modification.
